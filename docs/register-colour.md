# Register colour of the open rows

Generated by `tools/regmap.py --all`. No build required; both bodies are
read from the linked images, aligned at SHAPE level, and the register
operands are read off both sides of every aligned pair.

## Why a global bijection is the right question

A physical register is not a value -- the same register holds different
values in different parts of a function -- so "does `esi` differ" is not a
meaningful question. What is meaningful is whether **one** renaming
explains the whole body. If it does, the same live ranges were simply given
different physical registers: an allocator tie with no source correlate,
the register analogue of wave 7's compiler-temporary finding. If no single
renaming works, the colouring is re-decided somewhere, which is consistent
with the live ranges themselves differing -- and that has a source
correlate.

permutations, which is the opposite of what the frame screen found for

## Method notes and traps

- **Callee-saved `push`/`pop` are excluded from the evidence.** The
  prologue saves and the epilogue restores in a canonical order whatever
  the allocator did, so those operands do not follow the renaming. On
  `TextureImpl::SetImage` they were 4 of 35 pairs and were the only thing
  standing between it and a perfect bijection.
- **Jump tables must be trimmed first.** A switch table inside the
  function's extent disassembles as nonsense and invents register pairs.
  `Infocenter::HandleKeyPress` read as 9 regions with the table in and 3
  with it out. `slotmap.py` now trims tables too, via the dispatch
  `jmp dword ptr [reg*4 + BASE]`, which gives the table's start exactly.
- A region boundary requires a **sustained** conflict; one conflicting
  pair is alignment noise.

## Regression pair

Both reproduce a hand analysis from an earlier wave:

- `0x100a12a0 TextureImpl::SetImage` -> PERMUTATION, `ebx`<->`ebp`,
  explaining 100% of 23 operand pairs. Wave 1 read this row by hand as
  "the entire residue is an `ebx`/`ebp` exchange plus one scheduling
  shift".
- `0x1006fda0 Infocenter::HandleKeyPress` -> REGIONAL, 3 regions, majority
  map identity with 7 of 52 pairs unexplained, all `eax`<->`ecx` and all
  contiguous. Wave 1 read this row by hand as "the whole -8 is `eax`/`ecx`
  in the `e_playCutscene` case". Three regions is exactly right:
  identity, swapped, identity.
